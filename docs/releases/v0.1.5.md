# Graphcraft v0.1.5

## Release notes

- Adds task-specific agent-authored graphs, runtime-enforced governance, held-out completion
  checks, evidence trajectories, bounded amendments, and grounded context selection.
- Extends durable execution through exact-session recovery, coordinated pause and stop, token-free
  waits, detached supervision, and claim-act-confirm reconciliation for local and GitHub effects.
- Adds `pushed`, `pr_open`, and `pr_green` finish lines, including exact-SHA review and CI handling,
  plus a local read-only graph, evidence, recovery, and token viewer.
- Hardens repository scope, secret redaction, bounded artifact persistence, package installation,
  marketplace artifacts, matched benchmark controls, and trusted release verification.
- Stops committing generated distribution bundles so release checkouts stay clean and every
  published artifact is built and verified from source by the trusted release workflow.
- Fixes the release suite to validate the README registry-independent install example against the
  packaged version instead of a stale fixture; that stale assertion failed release CI and burned
  the v0.1.4 tag. The v0.1.2, v0.1.3, and v0.1.4 tags were never published.
- Runs per-push CI on macOS with the full cross-platform matrix available on demand and enforced
  by the release workflow.

## Persisted-format migration

- Runs created by the published v0.1.0 and v0.1.1 formats migrate forward to storage version 2 on
  first access under the run and migration locks.
- Graphcraft verifies the complete source snapshot, writes and fsyncs a full pre-migration backup,
  and publishes the new storage manifest only after the backup and migrated inventory validate.
- No manual migration is required. Future or unsafe formats fail closed without changing the run;
  preserved migration backups remain available under `.graphcraft/migration-backups/`.
